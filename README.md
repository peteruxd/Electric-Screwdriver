# Electric Screwdriver

3D-printable case parts for an electric screwdriver.

## Status: Work in Progress

This is a work in progress. Details such as snap joints, tolerances, and
fitment are not yet refined. Use at your own risk and test-fit before
final assembly.

## Files

- `Case Cap.stl` — top cap
- `Case_bottom.stl` — main case body
- `Button_Top.stl` — trigger button
- `motor_Cap.stl` — motor cap
